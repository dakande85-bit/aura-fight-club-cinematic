# Aura voiceovers — editorial uploads

Upload your own recording here using **GitHub > Add file > Upload files**. Accepted inputs: MP3, M4A, WAV, OGG, WEBM.

Files must be recordings you own. Do not commit copyrighted music or broadcaster audio, and do not put private interviews here without permission. This folder is in a public repository: **uploaded recordings become public**. If your voice needs to remain private, do not upload it here; use the local renderer until a private media-storage backend is ready.

Suggested filenames:
- `dubois-wardley-short.m4a`
- `dubois-wardley-youtube.m4a`

Then run the manually triggered [AURA Creator workflow](../../.github/workflows/aura-creator-render.yml) and provide these relative paths.

**Warning:** GitHub is an interim publishing-workflow intake, not a private recording studio. The browser recording feature is local-only until an authenticated uploader is implemented.
